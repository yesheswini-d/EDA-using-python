## About the Project
This mini project focuses on Exploratory Data Analysis (EDA) using Python. It analyzes the given dataset, identifies patterns and trends, and presents useful insights through data visualization.

## Objective
- To understand and analyze the dataset.
- To perform data preprocessing and cleaning.
- To identify patterns and relationships in the data.
- To visualize the results using Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Files
- eda1.py to eda9.py – Python programs for data analysis
- .csv files – Dataset and processed data
- Results.pdf – Analysis results

## Methodology
1. Data collection
2. Data preprocessing
3. Exploratory data analysis
4. Data visualization
5. Result analysis

## Conclusion
The project demonstrates how Python can be used for data preprocessing, exploratory analysis, visualization, and extracting meaningful insights from data
